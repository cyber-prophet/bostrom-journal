# Применения

| Область | Применение |
|--------|-------------|
| **Наука** | Тезисы статьи как частицы; репликация = agree; неудавшаяся репликация = disagree |
| **Журналистика** | Проверка источников; несколько репортёров, подтверждающих один факт |
| **Право** | Условия договора; показания свидетелей; цепочки доказательств |
| **Стандарты** | Технические спецификации; согласие сообщества по соглашениям |
| **Образование** | Проверка знаний; рецензирование объяснений |
| **Выравнивание ИИ** | ИИ-агенты взаимодействуют через киберлинки; измеримая агрегация предпочтений |
| **Цепочки поставок** | Утверждения о продукте; сертификация; журналы аудита |

Двенадцати соглашений на одном примитиве — подтверждение ребра, deny, update, quote, agree, disagree, pro, con, question, answer, author, same — достаточно, чтобы выразить сложные совместные рабочие процессы. Поскольку нейронами могут быть и люди, и контракты, те же соглашения применимы к взаимодействиям ИИ-агентов без дополнительной инфраструктуры.
