# Applications

| Domain | Application |
|--------|-------------|
| **Science** | A paper's claims as particles; replication = `agree_particle`; failed replication = `disagree_particle` |
| **Journalism** | Source verification; several reporters independently stating one fact |
| **Law** | Contract terms; witness testimony; chains of evidence |
| **Standards** | Technical specifications; community agreement on conventions |
| **Education** | Knowledge testing; review of explanations |
| **AI alignment** | AI agents interact through cyberlinks; measurable preference aggregation |
| **Supply chains** | Statements about a product; certification; audit logs |

Twelve conventions on one primitive
— `confirm_edge`/`confirm_link`, `deny_edge`/`deny_link`, `update_edge`, `quote_particle`, `agree_particle`, `disagree_particle`, `pro`, `con`, `question`, `answer_edge`, `author_particle`, `same` —
plus edge repetition, which has no special CID of its own,
are enough to express complex collaborative workflows.
Since both humans and contracts can be signers,
the same conventions apply to AI-agent interactions without additional infrastructure.
