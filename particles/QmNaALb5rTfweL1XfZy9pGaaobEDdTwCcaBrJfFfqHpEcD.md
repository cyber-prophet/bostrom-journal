# Отрицание ребра и киберлинка

```
A - CID
B - CID
neuron - CID нейрона оспариваемого киберлинка

hash("deny_edge") → hash(A, B)               # отрицание ребра
hash("deny_link") → hash(A, B, neuron)  # отрицание конкретного киберлинка
```

Две цели отрицания — две семантики, и у каждой своё слово:
- `deny_edge` → `hash(A, B)` — оспаривает само утверждение `A → B`: оно неверно, кто бы его ни опубликовал
- `deny_link` → `hash(A, B, neuron)` — оспаривает конкретный киберлинк конкретного нейрона: запись недействительна — например, как спам, — без мнения о самом утверждении

В отличие от `update_edge` и `quote_particle`, которые встраивают свой операнд в CID источника, `hash("deny_edge")` и `hash("deny_link")` — фиксированные CID; отрицается то, на что они указывают.
