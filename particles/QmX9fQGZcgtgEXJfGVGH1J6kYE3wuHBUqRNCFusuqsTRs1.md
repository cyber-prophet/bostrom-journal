# Цитаты

```
A - CID
B - CID, content(B) — подстрока content(A) (независимо проверяемо)

hash("quote", A) → B       # "B — добросовестная выдержка из A"
```

Когда ребро-цитату повторяет другой подписант, его повторение утверждает, что выдержка добросовестна; `hash("deny") → hash(hash("quote", A), B)` оспаривает её как вводящую в заблуждение вне контекста.
