# Измеримый консенсус

Для любого утверждения `A → B`:
- Посчитать киберлинки разных нейронов с этим ребром → уровень поддержки
- Посчитать киберлинки-отрицания → уровень спора
- Взвесить нейроны по политике чтения (например, по репутации) → взвешенный консенсус
- Отслеживать во времени → эволюция консенсуса

Действительность не решает ни один центральный орган. Вместо этого:
- Делаются утверждения (создаются киберлинки)
- Другие подтверждают или отрицают (новые киберлинки)
- Агрегация выявляет консенсус
- Мнения меньшинства остаются видимыми (не цензурируются, просто оказываются в меньшинстве)

```
Consensus(statement) = f(confirms, denies, neuron_weights, time_decay)
```

Точная формула — это вопрос политики чтения. Киберграф предоставляет сырые данные.

Мнение нейрона тоже живёт во времени: можно подтвердить утверждение, а позже отвергнуть его. Киберлинки нейрона упорядочены (см. «Основы»), поэтому его актуальное мнение естественно читать как последнее по времени; прежние остаются видимой историей. Тем же способом отзывается собственный киберлинк: `hash("deny") → hash(A, B, neuron)`, где нейрон — сам отзывающий.
