# Измеримый консенсус

Для любого утверждения `A → B`:
- Посчитать киберлинки разных подписантов с этим ребром → уровень поддержки: сколько подписантов утверждают то же самое
- Посчитать `confirm_edge` этого ребра → поддержка тех, кто утверждения своим не делает
- Посчитать `deny_edge` этого ребра → уровень спора
- Посчитать `confirm_link` и `deny_link` → действительность записей (отдельная ось: об утверждении она ничего не говорит)
- Взвесить подписантов по политике чтения (например, по репутации) → взвешенный консенсус
- Отслеживать во времени → эволюция консенсуса

Действительность не решает ни один центральный орган. Вместо этого:
- Делаются утверждения (создаются киберлинки)
- Другие повторяют, подтверждают или отрицают (новые киберлинки)
- Агрегация выявляет консенсус
- Мнения меньшинства остаются видимыми (не цензурируются, просто оказываются в меньшинстве)

```
Consensus(statement) = f(repeats, confirms, denies, signer_weights, time_decay)
```

Точная формула — это вопрос политики чтения. Киберграф предоставляет сырые данные.

Мнение подписанта тоже живёт во времени: можно сделать утверждение или подтвердить чужое, а позже отвергнуть его. Киберлинки подписанта упорядочены (см. «Основы»), поэтому его актуальное мнение естественно читать как последнее по времени; прежние остаются видимой историей. Смена мнения об утверждении — это `{"op":"deny_edge"} → {"cid_from":A,"cid_to":B}`; отзыв собственной записи — `{"op":"deny_link"} → {"cid_from":A,"cid_to":B,"signer":signer}`, где `signer` — CID самого отзывающего.
