# Обновление ранее опубликованного ребра

```
A - CID из исходного ребра
B - другой CID из исходного ребра
C - новый CID, замещающий B

A → B                            # исходное ребро
A → C                            # вспомогательное ребро — C достижим из A (необязательное)
hash("update_edge", hash(A, B)) → C   # авторитетное — помечает C как обновление ребра
```

Обновления заново исходят из того же CID `hash("update_edge", hash(A, B))`, поэтому обновление само может быть обновлено: самое свежее ребро из этого источника — текущая версия. Источник один для всех, поэтому опубликовать обновление может кто угодно; чьи обновления принимать — например, только нейрона исходного киберлинка — решает политика чтения. И как любое ребро, ребро обновления само адресуемо — `hash("update_edge", hash(A, B)) → C` может быть подтверждено через `confirm_edge` или отвергнуто через `deny_edge` другим нейроном.
