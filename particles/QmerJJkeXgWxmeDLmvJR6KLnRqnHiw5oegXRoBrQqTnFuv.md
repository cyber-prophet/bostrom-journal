# Применения

| Область | Применение |
|--------|-------------|
| **Наука** | Тезисы статьи как отдельные файлы; репликация = `agree`; неудавшаяся репликация = `disagree` |
| **Журналистика** | Проверка источников; несколько репортёров, независимо утверждающих один факт |
| **Право** | Условия договора; показания свидетелей; цепочки доказательств |
| **Стандарты** | Технические спецификации; согласие сообщества по соглашениям |
| **Образование** | Проверка знаний; рецензирование объяснений |
| **Выравнивание ИИ** | ИИ-агенты взаимодействуют через киберлинки; измеримая агрегация предпочтений |
| **Цепочки поставок** | Утверждения о продукте; сертификация; журналы аудита |

Двенадцати соглашений на одном примитиве — `confirm`, `deny`, `update`, `quote`, `agree`, `disagree`, `pro`, `con`, `question`, `answer`, `author`, `same` — плюс повторения ребра, у которого специального CID нет, достаточно, чтобы выразить сложные совместные рабочие процессы. Поскольку подписантами могут быть и люди, и контракты, те же соглашения применимы к взаимодействиям ИИ-агентов без дополнительной инфраструктуры.
