# Обновление ранее опубликованного ребра

```
A - CID из исходного ребра
B - другой CID из исходного ребра
C - новый CID, замещающий B

A → B                            # исходное ребро
A → C                            # вспомогательное ребро — C достижим из A (необязательное)
hash("update", hash(A, B)) → C   # авторитетное — помечает C как обновление ребра
```

Обновления заново исходят из того же CID `hash("update", hash(A, B))`, поэтому обновление само может быть обновлено: самое свежее ребро из этого источника — текущая версия. Источник один для всех, поэтому опубликовать обновление может кто угодно; чьи обновления принимать — например, только нейрона исходного киберлинка — решает политика чтения. И как любое ребро, ребро обновления само адресуемо — `hash("update", hash(A, B)) → C` может быть подтверждено `confirm`'ом или отвергнуто `deny`'ем другим нейроном.
