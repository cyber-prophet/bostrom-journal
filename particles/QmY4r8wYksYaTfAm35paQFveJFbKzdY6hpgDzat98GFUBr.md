# Измеримый консенсус

Для любого утверждения `A → B`:
- Посчитать киберлинки разных нейронов с этим ребром → уровень поддержки: сколько нейронов утверждают то же самое
- Посчитать `confirm_edge` этого ребра → поддержка тех, кто утверждения своим не делает
- Посчитать `deny_edge` этого ребра → уровень спора
- Посчитать `confirm_link` и `deny_link` → действительность записей (отдельная ось: об утверждении она ничего не говорит)
- Взвесить нейроны по политике чтения (например, по репутации) → взвешенный консенсус
- Отслеживать во времени → эволюция консенсуса

Действительность не решает ни один центральный орган. Вместо этого:
- Делаются утверждения (создаются киберлинки)
- Другие повторяют, подтверждают или отрицают (новые киберлинки)
- Агрегация выявляет консенсус
- Мнения меньшинства остаются видимыми (не цензурируются, просто оказываются в меньшинстве)

```
Consensus(statement) = f(repeats, confirms, denies, neuron_weights, time_decay)
```

Точная формула — это вопрос политики чтения. Киберграф предоставляет сырые данные.

Мнение нейрона тоже живёт во времени: можно сделать утверждение или подтвердить чужое, а позже отвергнуть его. Киберлинки нейрона упорядочены (см. «Основы»), поэтому его актуальное мнение естественно читать как последнее по времени; прежние остаются видимой историей. Смена мнения об утверждении — это `hash("deny_edge") → hash(A, B)`; отзыв собственной записи — `hash("deny_link") → hash(A, B, neuron)`, где `neuron` — CID самого отзывающего.
