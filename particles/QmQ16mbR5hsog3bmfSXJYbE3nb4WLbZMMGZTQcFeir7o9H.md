# Collaborative work on information

Cyberlinks connect files and, through them, signers:

```
Alice states:    A → B
Bob repeats:     A → B
Carol denies:    hash("deny_edge") → hash(A, B)
Dave quotes:     hash("quote_particle", A) → B
Erin confirms:   hash("confirm_edge") → hash(A, B)
```

The graph encodes not only "what is connected to what" but also "who believes what" — and this is open to querying and analysis.
